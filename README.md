# 🏥 HealthClinicPortal1

A simplified **health clinic management system** inspired by Rutgers University Health Centers. This Java-based application models essential features of a student clinic, including patient appointments, scheduling, billing, and medical records.

---

## 📋 Overview

HealthClinicPortal1 provides a backend system for managing core healthcare operations, built using polymorphic design principles. It simulates a real-world clinical portal that could be used by students, providers, and administrators to manage appointments, access records, and streamline operations.

---

## 🛠️ Features

- 📅 Schedule and manage appointments with medical providers
- 👩‍⚕️ Track patient profiles, visits, and medical records
- 🧾 Generate billing statements for each visit
- 🧠 Assign providers by specialty and availability
- 🕒 Timeslot-based scheduler with conflict resolution
- 🏢 Location management for multi-site clinics
